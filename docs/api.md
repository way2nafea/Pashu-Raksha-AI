# API Reference

Full interactive documentation is auto-generated by FastAPI and always
reflects the running code:

- Swagger UI: `GET /docs`
- OpenAPI schema: `GET /openapi.json`

All endpoints are namespaced under `/api/v1/`. Authenticated endpoints
require `Authorization: Bearer <token>`, obtained from `POST
/api/v1/auth/login` (OAuth2 password form: `username` + `password`).

## Endpoint groups

| Prefix | Purpose |
|---|---|
| `/auth` | login, logout, current-user |
| `/users` | user administration (SUPER_ADMIN create; admins list) |
| `/farms` | farm CRUD |
| `/animals` | animal registration + digital health passport |
| `/reports` | disease report submission (the core workflow entrypoint) |
| `/cases` | case queue, detail, assignment, status transitions |
| `/visits` | field visit records |
| `/treatments` | diagnosis + treatment records |
| `/lab` | sample request/status/result workflow |
| `/vaccinations` | vaccination records |
| `/gis` | map data (farms/cases/outbreaks), outbreak list |
| `/alerts` | alert feed, acknowledgement |
| `/dashboard` | government analytics (overview, lab, veterinary response) |
| `/sync` | offline batch report submission |
| `/audit` | audit log (SUPER_ADMIN / STATE_ADMIN) |

## Example: submit a disease report

```
POST /api/v1/reports
Authorization: Bearer <farmer_token>
Content-Type: application/json

{
  "animal_id": "...", "farm_id": "...", "species": "cattle",
  "symptoms": ["fever", "skin_lesions", "reduced_appetite"],
  "symptom_duration_days": 3, "severity": "severe",
  "affected_head_count": 2, "mortality_count": 1,
  "vaccination_status": "unvaccinated",
  "latitude": 19.3006, "longitude": 72.8508,
  "village": "Village A", "district": "Thane"
}
```

Returns the created report, full AI risk assessment, nearby-case count,
outbreak status (if triggered), and the resulting case — all in one
response, since this is the exact payload the farmer's result screen
renders.
